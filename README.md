## 先分清：你要“巴西访问快”，还是“平台认为你在巴西”

这两件事对应的产品完全不一样，混着选最容易花冤枉钱。

给巴西用户访问，决定体验的是机房到用户的物理距离。圣保罗本地的机房能做到个位数毫秒，巴西境内平均 20ms 左右，这是本地主机商反复强调的卖点。Evoxt 的圣保罗节点在这条线上，本地 IPv4、NVMe、1Gbps 端口，够用。

让平台认为你在巴西，决定成败的是 IP 属性。数据中心 IP 和住宅宽带 IP 在平台风控里归为两个类别，前者来自云厂商和 IDC 的地址段，后者归属本地宽带运营商。做巴西 TikTok 起号、发视频、开本土店的人愿意为“住宅 IP”多付几倍价钱，买的就是这个归属。Evoxt 的公开资料没有把巴西节点包装成住宅 IP，也没有针对 TikTok 的线路方案，官方对圣保罗的定位是巴西和南美业务部署、跨区域架构。拿它做账号运营，先自己查一下 IP 在检测工具里的归属再决定。

IP 是否独享是第二件事。Evoxt 每个实例配 1 个独立 IPv4，不与他人共用。这一条对多账号运营是必要条件，但不充分。

到中国的延迟是第三件事。巴西离中国的物理距离摆在那里，直连延迟天然在 300ms 以上，换哪家巴西 VPS 都一样。要稳定直播，通常得套一层香港、日本或新加坡的中转。Evoxt 自己在香港和日本大阪有优化线路节点，做中转是现成的，但中转机需要另外买、另外付钱。

## 常见问题

**巴西 VPS 一定要中转吗？**
给巴西用户访问的站点不需要，用户直连圣保罗就行。从中国远程管理、上传大文件、做直播，中转能明显改善体验，因为中国到巴西的直连线路不在任何一家 VPS 商的优化范围内。

**住宅 IP 和机房 IP 差在哪？**
机房 IP 来自云厂商和 IDC 的地址段，住宅 IP 归属本地宽带运营商。平台风控对两者的处理不一样，做账号运营的人为此付费。普通建站、跑 API 用不上住宅 IP，多花的钱换不来任何体验提升。

**500GB 月流量够不够？**
一个日访问几千 PV 的 WordPress 站点，加上系统更新和 SSH 流量，一个月通常用不到 200GB。视频、大文件下载、代理转发才吃流量，这类用途直接看 2TB 以上的档。

**月付还是年付？**
先用月付。巴西线路的实际表现取决于你的网络和用途，跑一周再决定要不要锁长期。VM-0.5 一个月三美元，买错了比买贵了划算。

**能不能只买巴西，不要其他地区？**
可以。Evoxt 各地区单独下单，巴西圣保罗和香港、日本、美国这些节点是分开的产品，配置档位一致，流量额度按线路不同。
